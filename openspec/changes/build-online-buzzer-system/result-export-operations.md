# 任務六操作與驗收

## 老師匯出

1. 在老師看板開啟「匯出定案成果」。活動進行中或結束後都能匯出歷史定案結果。
2. 檢查 Google Sheets 寫回預覽的工作表、題號、子空格、勝者、目標格及答案。按「確認覆寫」後，系統只更新預覽列出的答案格。新輪次定案後，須更新預覽才能確認新的範圍。
3. 從確認覆寫到讀回完成，請勿在 Google Sheets 修改結構。若系統提示結構變動，請先核對題號、子編號、合併與答案格位置。結構一旦變動，系統會停止寫入。
4. 「成功」表示已讀回所有目標格的文字。「失敗」請依畫面指示確認權限或工作表。「待確認」可先按「讀回核對」，也可在確認結構後按「重試此次寫回」。核對只讀取資料，重試使用先前確認的同一份答案。若要加入新定案的答案，請更新預覽後另外確認。
5. Google 授權失效時，按「重新授權 Google」並使用具有編輯權的帳號，返回匯出頁後再核對或重試。

「下載 CSV」包含所有已定案輪次的提交。正確、判錯與未審閱紀錄均會保留，題組每個子空格各佔一列。無資料時仍可下載十欄表頭。CSV 使用 UTF-8 BOM，可能觸發公式的答案前會加單引號，系統保存的答案與寫回 Google Sheets 的文字不受此格式影響。取消活動後，匯出功能會關閉。

## 本機自動驗收

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests/test_result_export.py
$env:BUZZER_BROWSER_TEST = '1'
$env:BUZZER_BROWSER_CHANNEL = 'chrome'
.\.venv\Scripts\python.exe -m pytest -q tests/test_round_review_browser.py -k export_page
```

服務測試涵蓋預覽失效、寫回鎖定、來源漂移、精確單題與題組映射、失聯核對與同快照重試、CSV 格式。Chrome 測試以獨立老師和學生工作階段操作實際頁面，使用測試替身處理 Google 授權與寫回。

## 指定 Google 測試複本驗收

需具備正式應用程式的 OAuth／Picker 設定、指定測試複本與有編輯權的 Google 測試帳號。使用課堂正式學習單會覆寫其答案，請先核對所選檔案是指定測試複本。

1. 在指定複本選用同時包含單題橫向合併作答格與雙格題組的工作表。先記錄目標及相鄰非目標格的內容、合併與格式。讓另一個未成功題保有可辨識的舊答案。
2. 用老師身分透過 Picker 匯入該工作表。安排一題單題及一題題組各有一組成功，另留一題無勝者。使用帶前後空白與換行的答案，以及以 `=1+1` 開頭的答案。
3. 關輪、審閱、定案後到匯出頁核對三個目標格，按「確認覆寫」，記錄系統是否顯示讀回成功。
4. 在 Google Sheets 核對單題寫入合併格左上角、題組寫入兩個子編號右側，以及原文空白、換行和類公式文字。核對題號、子編號、格式、合併、非目標格及未成功題均保持原樣。
5. 記錄實際結果、任何差異及測試日期。完成上述核對後再勾選任務 6.3。

### 2026-11-26 實測結果

- 透過正式應用程式授權及 Picker 匯入指定複本的「學習單」，辨識為 4 題、6 格。在獨立學生視窗提交第 1 題題組及第 3 題單題，老師關輪、審閱並定案。
- 確認覆寫後，應用程式回報寫回成功，並讀回核對三格文字及來源結構。第 1 題寫入 `H5`、`H6`，第 3 題寫入合併格左上角 `G11`。
- 另外比對寫入前後的 Google Sheets `A1:Z25`，只有上述三格的值改變，所有儲存格格式相同。第 2、4 題及題號、子編號維持原樣。`H5` 的 `=1+1` 存為文字，`H6`、`G11` 均保留兩個前導空白、換行及兩個尾端空白。
