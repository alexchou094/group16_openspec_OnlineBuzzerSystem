# Tasks

每組包含自己的測試及必要操作文件，最後一組處理跨模組整合驗收。Google 真實授權未就緒時可先完成純領域及 fake adapter 工作，真實讀寫驗收由實際結果勾核。

## 1. 建立專案基礎與外部驗證條件

- [x] 1.1 建立 Python Web、服務、領域、repository、adapter、HTML/CSS／JavaScript 與測試目錄，鎖定 FastAPI、Jinja2、測試及 Google 用戶端依賴；驗證乾淨環境可安裝並以單 worker 在 loopback 啟動。
- [x] 1.2 建立無敏感值的設定範例及忽略規則，文件說明憑證位置、本機啟動、重啟清空與獨立瀏覽器 context；依文件重現啟動並確認版本控制內無憑證。
- [x] 1.3 建立需求對齊檢核表，列出 C1–C9、E1–E6、11/22 接受的十項跨組規則、固定題序、整輪重算、定案鎖定、題組計數與 CSV；由組員記錄已確認的結果及其餘待確認事項。
- [x] 1.4 建立 Google OAuth／Picker 最小驗證流程，在指定測試複本確認選檔、讀取值與合併範圍、RAW 寫入及讀回，並測拒絕／過期／無權限；留下不含憑證的驗證紀錄與設定步驟，若失敗明列阻塞，不擅自切換服務帳號。

參見 [需求對齊檢核表](requirements-alignment.md) 與 [第 1 節人工測試及驗證紀錄](part1-manual-tests.md)。1.4 的本機工具與模擬測試已完成，指定 Google 測試複本的 G1、G2、G5、G6 已通過。G3、G4 依使用者指示跳過實測，並依此驗收範圍結案。

## 2. 活動、身分與輪次骨架

參見 [spec01 人工驗收紀錄](manual-test-report.md)，包含案例 01–09 的使用者回報與案例 10 的重現步驟。

- [x] 2.1 建立活動、組別、來源、題目、輪次、提交與結果模型及記憶體 repository；用模型／服務測試驗證活動隔離、唯一代碼及重啟後失效。
- [x] 2.2 實作老師與學生 session、建立活動時的組數上限、組號範圍驗證及 6 位數加入憑證；驗證 1 與 N 均可使用，空白、非整數與越界組號會被拒絕。驗證同組多裝置加入、重新整理恢復、缺少或錯誤憑證時拒絕加入，以及同組裝置都失去身分後可使用老師提供的憑證重新加入。
- [x] 2.3 實作老師專用操作授權與 CSRF／Origin 檢查；驗證同瀏覽器多分頁可控制、其他瀏覽器或裝置無法接管。測試同一老師 session 並行建立只成功一次、活動取消或結束後可再次建立，以及學生或其他老師的操作回應不洩漏私有資料。
- [x] 2.4 實作 PREPARING、OPEN、RESULTS、CANCELLED、FINISHED 與定案旗標的合法轉移，開輪固定題目／公平模式／倒數；測試零題、已成功題、未匯入、未定案開下一輪、僅準備中可取消及定案後提前結束。驗證速度與公平模式各自支援無倒數及 1、3600 秒，拒絕 0、3601 或非整數秒數。
- [x] 2.5 實作每活動鎖、可注入時鐘及接收序號，提供輪次與結果版本欄位；以並發服務測試證明手動關輪與自動到期只封存一次，並記錄單 process 限制。
- [x] 2.6 實作學生離組及老師刪除空組；驗證準備中或結果階段可離組、搶答中拒絕離組、改組不移轉歷史提交或成功次數。驗證老師能刪除從未提交的組別，刪除後舊裝置身分及憑證失效，曾提交者即使全被判錯也不可刪除。
- [x] 2.7 修正案例 10。保持伺服器運作，讓老師與學生分別關閉瀏覽器，再用各自原本的設定檔開啟原活動網址，驗證老師恢復控制權、學生恢復原組別，並確認伺服器重啟後舊活動失效。
- [x] 2.8 在學生首頁顯示「回到進行中的活動」入口。驗證學生回首頁後可用原組別身分返回，加入多個進行中活動時可分別選擇，離組、組別遭刪除或活動終止後不再顯示對應入口。驗證瀏覽器已快取舊版活動腳本時，新版頁面仍載入目前腳本。


## 3. 學習單解析與匯入

- [x] 3.1 建立 values、merge ranges、sheet id 的 adapter 輸入契約及 fake adapter；以兩份附件的等價測試資料驗證單題 6 題／6 格及混合 4 題／6 格，不把使用者 Downloads 絕對路徑寫入測試依賴。
- [x] 3.2 實作純解析器的動態表頭、題號正規化、合併續列、相鄰重複題號及逐題答案格映射；以原版與整體平移版 fixture 測試，確認程式沒有固定範例座標。
- [x] 3.3 實作題號連續性、子編號、孤立子格、表頭歧義及重疊目標檢查；逐項驗證位置錯誤訊息，以及任一錯誤都不留下部分題目或清除原匯入結果。
- [x] 3.4 整合 Google 工作表選取與讀取 adapter、來源結構指紋及原子匯入服務；測試單張自動選用、多張須手動選一張、取消、無權限、準備中替換、開輪後禁止重匯入。
- [x] 3.5 建立 HTML/CSS 匯入頁與題號／空格數摘要，補充支援版型及錯誤修正說明；以瀏覽器確認混合範例顯示 4 題／6 格，且錯誤不顯示內部憑證或堆疊。
- [x] 3.6 修正 Google Sheets 讀取工作表時不完整的 `fields` 參數；以 adapter 測試核對完整欄位選取語法及有效值與合併範圍的讀取，避免兩種學習單在解析前因欄位選取語法收到 HTTP 400。
- [x] 3.7 修正空白間隔列橫向合併跨過題號欄時被誤判的問題；以原始單題合併版型與平移版驗證 6 題／6 格及答案座標，並核對含值的橫向題號合併及孤立子編號仍被拒絕。

驗證使用等價學習單資料及模擬的 Google OAuth、Picker 和 Sheets 回應。真實 Google 帳號端到端驗收見 7.1。

## 4. 多題提交、截止與可見性

- [x] 4.1 實作完整題組提交及每格 500 Unicode 碼點上限，保存原文，僅空白檢查使用副本；驗證中文、補充平面字元、500／501 字、前後空白、換行、全空白、缺格、多格、非開放題與偽造組別，整筆拒絕不占用機會。
- [x] 4.2 實作活動／輪次／題目／組別唯一提交及重送結果；以同組兩裝置並發測試證明僅一筆成功，原時間序號不變，下一輪同題可以重答。
- [x] 4.3 實作單調截止、自動關輪與請求時到期檢查；以可控時鐘驗證截止前、恰等於截止、截止後、手動關輪競爭及舊輪次提交不混入新輪。
- [x] 4.4 實作角色投影與可見版本；HTTP 測試驗證學生僅取得本輪題目、本組提交及已定案成功次數，無當輪排名或他組資訊；老師看板只提供提交先後，不含暫估順位。驗證他組提交不透過版本、ETag、全域接收序號或流水 id 洩漏。
- [x] 4.5 建立老師看板與學生多行答案表單、輪詢與倒數；瀏覽器驗證答案空白換行原樣顯示、500 字提示、老師提交先後而無暫估順位、學生本組成功次數，以及兩秒同步、延遲回應、無倒數、斷線與提交回應遺失提示。
- [x] 4.6 補充組號加入、憑證備援、離組、刪除空組、同組提交及截止操作說明；驗證老師看板可查閱各組憑證，學生只可查看本組憑證，公開結果不含憑證。檢查答案的 HTML 特殊文字安全呈現，並確認未關輪時學生畫面及網路回應均不顯示他組進度。

## 5. 排序、判錯與定案

- [x] 5.1 實作關輪固定題序及速度候選排序；測試同時間戳以接收序號分先後、判錯不改題序，第一候選未審閱不得算勝者，同組兩題皆經確認可成功兩次。
- [x] 5.2 實作公平模式依歷史基準與前題已確認勝者排序下一題；測試按成功次數再接收先後審閱、甲乙兩題分配、題組一次、速度輪帶入公平輪、中途新組零基準，以及後題等待前題、不顯示假定順位。
- [x] 5.3 實作三態審閱與當前候選游標，逐筆判錯至首筆正確即停止，不須原因；測試錯、錯、對後的所有答案維持未審閱，只顯示失敗，禁止跳號及繼續判錯尾段，題組任一格錯則整筆判錯。
- [x] 5.4 實作撤銷及基準重算；測試清除該題撤銷處起與後續題目判定、原時間與固定題序不變、前題改判後題須重審、反覆重算不重複加分，及過期版本衝突。
- [x] 5.5 整合審閱完成檢查與定案快照；測試每題首筆正確／全錯／無提交才可定案，勝者後未審閱不阻擋且不算答對，冪等定案、定案後不可改判、全錯題可重開及成功題不可重開。

- [x] 5.6 建立結果頁、當前候選審閱、撤銷影響提示及操作說明；瀏覽器驗證關輪後才公開判錯、待審閱／暫定／定案區別、前兩錯第三對後續僅失敗、重審同步，以及未定案不可下一輪或結束。
