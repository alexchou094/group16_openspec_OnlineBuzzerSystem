# Tasks

每組包含自己的測試及必要操作文件，最後一組處理跨模組整合驗收。Google 真實授權未就緒時可先完成純領域及 fake adapter 工作，真實讀寫驗收由實際結果勾核。

## 1. 建立專案基礎與外部驗證條件

- [ ] 1.1 建立 Python Web、服務、領域、repository、adapter、HTML/CSS／JavaScript 與測試目錄，鎖定 FastAPI、Jinja2、測試及 Google 用戶端依賴；驗證乾淨環境可安裝並以單 worker 在 loopback 啟動。
- [ ] 1.2 建立無敏感值的設定範例及忽略規則，文件說明憑證位置、本機啟動、重啟清空與獨立瀏覽器 context；依文件重現啟動並確認版本控制內無憑證。
- [ ] 1.3 建立需求對齊檢核表，列出 C1–C9、E1–E6、11/22 接受的十項跨組規則、固定題序、整輪重算、定案鎖定、題組計數與 CSV；由組員記錄已確認的結果及其餘待確認事項。
- [ ] 1.4 建立 Google OAuth／Picker 最小驗證流程，在指定測試複本確認選檔、讀取值與合併範圍、RAW 寫入及讀回，並測拒絕／過期／無權限；留下不含憑證的驗證紀錄與設定步驟，若失敗明列阻塞，不擅自切換服務帳號。

## 2. 活動、身分與輪次骨架

參見 [spec01 人工驗收紀錄](manual-test-report.md)，包含案例 01–09 的使用者回報與案例 10 的重現步驟。

- [x] 2.1 建立活動、組別、來源、題目、輪次、提交與結果模型及記憶體 repository；用模型／服務測試驗證活動隔離、唯一代碼及重啟後失效。
- [x] 2.2 實作老師與學生 session、建立活動時的組數上限、組號範圍驗證及 6 位數加入憑證；驗證 1 與 N 均可使用，空白、非整數與越界組號會被拒絕。驗證同組多裝置加入、重新整理恢復、缺少或錯誤憑證時拒絕加入，以及同組裝置都失去身分後可使用老師提供的憑證重新加入。
- [x] 2.3 實作老師專用操作授權與 CSRF／Origin 檢查；驗證同瀏覽器多分頁可控制、其他瀏覽器或裝置無法接管。測試同一老師 session 並行建立只成功一次、活動取消或結束後可再次建立，以及學生或其他老師的操作回應不洩漏私有資料。
- [x] 2.4 實作 PREPARING、OPEN、RESULTS、CANCELLED、FINISHED 與定案旗標的合法轉移，開輪固定題目／公平模式／倒數；測試零題、已成功題、未匯入、未定案開下一輪、僅準備中可取消及定案後提前結束。驗證速度與公平模式各自支援無倒數及 1、3600 秒，拒絕 0、3601 或非整數秒數。
- [x] 2.5 實作每活動鎖、可注入時鐘及接收序號，提供輪次與結果版本欄位；以並發服務測試證明手動關輪與自動到期只封存一次，並記錄單 process 限制。
- [x] 2.6 實作學生離組及老師刪除空組；驗證準備中或結果階段可離組、搶答中拒絕離組、改組不移轉歷史提交或成功次數。驗證老師能刪除從未提交的組別，刪除後舊裝置身分及憑證失效，曾提交者即使全被判錯也不可刪除。

## 3. 學習單解析與匯入

- [ ] 3.1 建立 values、merge ranges、sheet id 的 adapter 輸入契約及 fake adapter；以兩份附件的等價測試資料驗證單題 6 題／6 格及混合 4 題／6 格，不把使用者 Downloads 絕對路徑寫入測試依賴。
- [ ] 3.2 實作純解析器的動態表頭、題號正規化、合併續列、相鄰重複題號及逐題答案格映射；以原版與整體平移版 fixture 測試，確認程式沒有固定範例座標。
- [ ] 3.3 實作題號連續性、子編號、孤立子格、表頭歧義及重疊目標檢查；逐項驗證位置錯誤訊息，以及任一錯誤都不留下部分題目或清除原匯入結果。
- [ ] 3.4 整合 Google 工作表選取與讀取 adapter、來源結構指紋及原子匯入服務；測試單張自動選用、多張須手動選一張、取消、無權限、準備中替換、開輪後禁止重匯入。
- [ ] 3.5 建立 HTML/CSS 匯入頁與題號／空格數摘要，補充支援版型及錯誤修正說明；以瀏覽器確認混合範例顯示 4 題／6 格，且錯誤不顯示內部憑證或堆疊。

## 4. 多題提交、截止與可見性

- [ ] 4.1 實作一次提交所有子空格的服務與 API，組別只從 session 取得；測試任意答題順序、空白、缺格、多格、非開放題與偽造組別，無效提交不占用機會。
- [ ] 4.2 實作活動／輪次／題目／組別唯一提交及重送結果；以同組兩裝置並發測試證明僅一筆成功，原時間序號不變，下一輪同題可以重答。
- [ ] 4.3 實作單調截止、自動關輪與請求時到期檢查；以可控時鐘驗證截止前、恰等於截止、截止後、手動關輪競爭及舊輪次提交不混入新輪。
- [ ] 4.4 實作老師及各學生組別的狀態投影與可見版本；HTTP 測試確認他組當輪答案、狀態、數量、順位均不可取得，且他組提交不透過學生版本、ETag、全域接收序號或流水 id 洩漏。
- [ ] 4.5 建立 HTML/CSS 老師看板與學生多題表單、原生 JavaScript 每秒輪詢與倒數；以瀏覽器測試兩秒同步、延遲舊回應捨棄、無倒數、斷線及提交回應遺失提示。
- [ ] 4.6 補充組號加入、憑證備援、離組、刪除空組、同組提交及截止操作說明；驗證老師看板可查閱各組憑證，學生只可查看本組憑證，公開結果不含憑證。檢查答案的 HTML 特殊文字安全呈現，並確認未關輪時學生畫面及網路回應均不顯示他組進度。

## 5. 排序、判錯與定案

- [ ] 5.1 實作關輪固定題序及純速度排序，無提交題置後；單元測試覆蓋同時間戳、接收序號、最早提交者後來判錯但題序不變，以及同組最快可贏兩題。
- [ ] 5.2 實作公平模式由歷史基準逐題排序、候選順位與勝出理由；測試甲乙兩題分配、題組只算一次、速度輪成功帶入公平輪及中途新組基準零。
- [ ] 5.3 實作判錯／撤銷判錯與整輪純重算，保留原始答案及版本控制；測試題一甲改判後題二勝者互換、非勝者判錯、題組整筆排除及反覆重算不重複累加。
- [ ] 5.4 整合定案與歷史快照，拒絕過期確認及定案後改判；測試重複確認冪等、未判錯視為接受、全錯題下輪重新開放及成功題不能重開。
- [ ] 5.5 建立結果 HTML/CSS 頁、暫定／定案標示、勝出理由、判錯／撤銷與受影響題目提示，補充審閱操作說明；以老師與學生瀏覽器驗證整輪更新一致且未定案不能下一輪／結束。

## 6. 寫回與 CSV

- [ ] 6.1 實作已定案成果快照、預覽及老師確認，將外部 I/O 移出活動鎖；服務測試驗證未定案資料不納入、無結果不呼叫外部、新定案使舊預覽失效及同時僅一個寫回嘗試。
- [ ] 6.2 實作寫前重讀／重解析與結構指紋比對；以 fake adapter 測試插列、改題號、改合併、刪工作表、相同表頭但答案位置變更均停止，只有答案文字變更則可依確認覆寫。
- [ ] 6.3 實作 RAW 精確目標批次寫入及讀回核對；測試單題／題組映射、類公式文字、編號與格式保留、未成功題不動，並以指定 Google 測試複本核對相同行為。
- [ ] 6.4 實作成功／失敗／待確認狀態、同快照核對與重試；模擬寫後逾時、回應遺失、權限失效、寫後結構漂移，驗證不誤報、不重複加分、不盲目回滾且較新定案不擴大舊重試。
- [ ] 6.5 實作已定案提交 CSV，固定九欄、數字組號、子格拆列、判錯順位留空、UTF-8 BOM、時間與安全引用；用逗號／引號／換行／公式前綴 fixture 測試欄位及資料筆數，未定案不納入。驗證可匯出但無資料時僅含表頭，已取消活動禁止下載。
- [ ] 6.6 建立匯出預覽／進度／重試 HTML/CSS 頁及操作文件，說明覆寫範圍、CSV 文字保護與寫回期間不修改結構；瀏覽器驗證老師可用、學生不可用、活動中可匯出歷史定案成果，以及已取消活動拒絕寫回預覽、寫回與 CSV 下載。

## 7. 整合與交付驗收

- [ ] 7.1 以老師與至少兩組獨立瀏覽器 context 執行完整流程：Google 匯入、多題提交、速度與公平差異、跨題判錯重算、撤銷、定案、全錯下一輪、結束及寫回／CSV；保存實際自動測試結果，確認兩秒同步及角色資料隔離。
- [ ] 7.2 由非主要實作者依各模組操作文件進行人工驗證，覆蓋兩份範例及一份不同位置學習單，逐一核對原表非目標內容；將實際結果對應 C1–C9／E1–E6，任何 Google 或外部對齊未完成項目不得記為通過。
- [ ] 7.3 核對程式、specs、design、操作文件與五分鐘內 demo 腳本一致，檢查敏感資訊未入版本控制；彙整啟動／測試指令、已知限制、組員驗收與課程交付清單，完成後供使用者審閱，不自行發布或提交課程資料。
