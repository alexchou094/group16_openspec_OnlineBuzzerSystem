## 11/22 已接受的跨組規則

依 [proposal](proposal.md) 及 Git 變更 `674f7d5` 記錄。

| 項目 | 已接受行為 |
| --- | --- |
| 1. 組數上限 | 老師建立活動時指定正整數 N。 |
| 2. 組號 | 學生以 1～N 的整數組號加入。 |
| 3. 加入憑證 | 既有組使用六位數憑證，可由同組裝置或老師看板提供。 |
| 4. 學生離組 | 準備中及結果階段可離組，原組的歷史繼續歸原組。 |
| 5. 刪除空組 | 老師能刪除從未有效提交的組別，舊身分及憑證失效。 |
| 6. 老師控制權 | 控制權綁定建立活動的瀏覽器工作階段，同工作階段的分頁共用。 |
| 7. 進行中活動上限 | 每個老師工作階段同時只能有一個進行中活動。 |
| 8. 活動取消 | 只有準備中可取消，取消後拒絕新加入、提交、寫回及 CSV。 |
| 9. 可選倒數 | 速度與公平模式均可不設倒數，或設定 1～3600 的整數秒。 |
| 10. 工作表選擇 | 單張工作表自動選用，多張時由老師選擇。 |

## 其他應逐項核對的 OpenSpec 基線

| 項目 | 預期行為 |
| --- | --- |
| 固定題序 | 關輪以各題最早有效提交排序，無提交題依題號置後。判錯及撤銷時沿用同一題序。 |
| 整輪重算 | 每次從開輪時保存的成功次數基準出發，依題序重算所有順位與勝者。 |
| 定案鎖定 | 老師確認最新結果後鎖定該輪。定案後可開下一輪或提前結束。 |
| 題組計數 | 一個題號計一個競賽題及一次勝出，另外顯示空格數。混合範例為 4 題、6 格。寫回只填對應答案格，保留子編號。 |
| CSV | 欄序為輪次、題號、子空格、組別、答案、送出時間、順位、是否成功、是否被判錯。題組拆列，判錯順位留空，只匯出已定案資料。 |
