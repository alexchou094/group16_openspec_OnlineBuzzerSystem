逐份執行：

1. 寫入前保留整張使用範圍的值／公式、格式、列高欄寬、合併範圍與其他工作表基準，記錄涵蓋範圍與遮蔽後附件位置。於未成功題保留可辨識的舊答案。
2. 用正式 Picker 匯入，核對題數、格數、子格。S 選第 1、3 題；M/P 選第 1 題題組與第 3 題單題。提交含兩個前後空白與換行的文字，以及 `=1+1`；逐筆審閱、定案。
3. 核對預覽目標只包含定案勝者。確認覆寫，等待讀回成功；若為失敗／待確認，記錄原提示與核對結果，不填通過。
4. 逐格核對所有目標原文，確認類公式答案是文字。把整個使用範圍扣除預覽目標逐格比對前後值／公式；另核對格式、題號、子編號、敘述、合併範圍、其他工作表及未成功題。每一差異記錄座標、原值、後值、預期與實際。
5. 下載 CSV，核對十欄、題組拆列、三態、判錯順位空白、全部定案提交及文字保護。記錄通過／失敗／未執行，驗收者簽名並附遮蔽證據。
